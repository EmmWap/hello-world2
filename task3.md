Describe the difference between fetch and pull and show (briefly) how each would be used. AC3.4

Fetch downloads the latest data from a remote repository onto your local machine but does not merge with the files on your local machine which means you can see the updates but not use or change them.

Pull downlaods the latest data from a remote repository onto your local machine and merges them with the files on your local machine allowing you to updates and change them.
